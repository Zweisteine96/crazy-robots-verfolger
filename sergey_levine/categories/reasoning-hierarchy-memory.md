# 1E · 具身推理、层级控制、可操控接口与记忆

## 1. 这个方向在研究什么

让机器人完成几分钟到十几分钟的长任务（做三明治、清理厨房、买菜），仅靠"看一眼、出一段动作"的端到端策略不够。这一类论文研究如何把 VLA 组织成一个**有推理、有层级、有记忆、可被操控**的系统：

1. **具身推理（embodied reasoning / robot chain-of-thought）**：让策略在输出动作前先"想"——预测子任务、运动描述、物体位置等中间表示。为什么有效？能否做得更快？
2. **层级控制**：一个高层"大脑"（VLM）理解复杂指令和用户反馈、决定下一步；一个低层 VLA 执行。两者之间的**接口**应该是什么——只是一句话，还是子任务、运动方式、像素坐标、子目标图像？
3. **记忆**：长任务需要记住"哪几步做完了"（长期、语义）和"手挡住的那个物体在哪"（短期、视觉）。记忆应该是什么形态？
4. **上下文内适应**：不更新参数，只把过去的执行结果放进上下文，系统能否学会低层策略的 affordance、学会更好地探索？

**为什么重要**：这是 VLA 从"技能执行器"变成"任务完成者"的必经之路。2025 年是这一类别爆发的一年（6 篇），说明随着 π0.5 等基础模型能力成熟，研究重心转向了如何组织和调用它们。

## 2. 论文逐篇分析（按时间）

### 2024

**[ECoT: Robotic Control via Embodied Chain-of-Thought Reasoning](https://arxiv.org/abs/2407.08693)**（2024-07）  
VLM 最令人兴奋的能力是迭代推理，能否带进机器人？朴素的 CoT prompting 对标准 VLA 效果差（训练样本太简单），且纯语义的子任务推理不够——机器人的推理必须 grounded 在感知与状态上。ECoT 训练 VLA 在预测动作前进行多步推理：计划、子任务、运动、以及**视觉 grounded 的特征**（物体边界框、末端位置）；并设计了在大型机器人数据集上生成 ECoT 合成训练数据的可扩展流水线。在困难泛化任务上把 OpenVLA 的绝对成功率提高 28%，**无需额外机器人数据**；副产品是人能更容易解读策略失败并用自然语言纠正。**意义**：本类别起点，"合成推理数据"这一手法被 Steerable Policies 沿用。

### 2025

**[Reflective Planning: VLMs for Multi-Stage Long-Horizon Robotic Manipulation](https://arxiv.org/abs/2502.16707)**（2025-02）  
VLM 缺少操作所需的细致物理理解和长时域推理能力（误差复合）。提出一个**测试时计算框架**：用一个生成模型**想象未来世界状态**，用这些预测引导动作选择，并批判性地反思潜在的次优之处来精炼推理，迭代改进预训练 VLM。显著超过多个商业 SOTA VLM 以及 MCTS 等后训练方法。**意义**：这是本报告中少数把"想象未来"（world model）显式用于高层规划的工作，且用法是反思式的而非搜索式的。

**[Hi Robot: Open-Ended Instruction Following with Hierarchical VLA Models](https://arxiv.org/abs/2502.19417)** †（2025-02）  
开放世界的 generalist 不仅要推理步骤，还要处理复杂指令、提示甚至执行中的反馈——"能给我做个素食三明治吗""我不喜欢那个"。系统用 VLM 组成层级：先对复杂 prompt 和用户反馈推理出最合适的下一步，再用低层动作执行。与只能完成"拿起杯子"的直接指令跟随不同，它能在执行中纳入情境反馈（"那不是垃圾"）。在单臂、双臂、双臂移动三种平台上验证：清理凌乱桌面、做三明治、购物。**意义**：确立了 VLM（高层）+ VLA（低层）的层级范式，也暴露了其接口问题——高层只能用自然语言指令驱动低层。

**[Training Strategies for Efficient Embodied Reasoning](https://arxiv.org/abs/2505.08243)** †（2025-05）  
机器人 CoT 有效但有局限：需要专门的推理数据、推理慢。要设计更好的方法，必须先搞清**为什么推理有帮助**。假设三种机制——(1) 更好的表征学习、(2) 更好的学习课程化、(3) 更强的表达力——并设计简单变体逐一隔离测试。发现：**学习生成推理确实带来更好的 VLA 表征，而"注意到"推理内容才能真正利用这些特征改进动作预测**。据此提出两个轻量的机器人推理配方，在 LIBERO-90 上达到 SOTA，推理速度比标准机器人推理快 3 倍。**意义**：与 1B 类别的 Why Chunking 同属"机理拆解"型论文——先搞清为什么有效，再设计更便宜的替代。

**[Behavioral Exploration: Learning to Explore via In-Context Adaptation](https://arxiv.org/abs/2507.09041)**（2025-07）  
人类能在几次交互内快速探索和适应，算法却依赖随机探索和缓慢的梯度更新。受 in-context learning 与大规模 BC 启发，提出 **behavioral exploration**：训练智能体内化"在专家行为空间中探索与适应"的含义。给定专家示范数据集，训练一个**长上下文生成模型**，条件于过去观测的上下文以及"该专家行为相对上下文有多探索性"的度量，预测专家动作。这使模型不仅模仿专家，还能通过把自己的交互历史喂进上下文，**选择与之前不同的专家行为**，实现快速在线适应与有目标的"专家式"探索。在仿真运动与操作及真实操作上验证。**意义**：把"探索"从 RL 的随机噪声变成 BC 模型的一种上下文条件能力。

**[CAST: Counterfactual Labels Improve Instruction Following in VLA Models](https://arxiv.org/abs/2508.13446)**（2025-08，RA-L 2026）  
VLA 难以跟随细粒度指令，原因之一是机器人数据集缺少语义多样性和语言 grounding——对相似观测缺少细粒度的任务多样性。方法：用 VLM 为已有数据生成**反事实标签**，增加语言 grounding 的多样性与粒度。在 3 个室内外环境的视觉语言导航实验中，反事实重标注（**无需额外采集**）显著改善指令跟随，成功率比未增强数据训练的 VLA 翻倍；操作 VLA 上在有干扰物的任务中也有类似增益。**意义**：解决层级系统中"高层说的话低层听不懂"的数据侧原因。

**[LITEN: Learning Affordances at Inference-Time for VLA Models](https://arxiv.org/abs/2510.19752)**（2025-10）  
解决复杂任务常需多次尝试：失败后反思、改变策略。VLA 缺乏在失败时情境化、动态地调整行为的能力。LITEN 把 VLA 低层策略连接到一个高层 VLM，后者**把过去经验放进上下文**，从而学习低层 VLA 的 affordance 与能力。在两个阶段之间迭代：推理阶段生成并执行给低层 VLA 的计划；评估阶段反思执行结果、得出有用结论放进未来的推理上下文。与非机器人领域的自我精炼不同，LITEN 必须对非结构化的真实轨迹（原始视频）做反思，因此评估阶段需要结构化的 guiderails。实验表明它能从过去经验中学习，生成使用**高 affordance 指令**的计划来完成长时域任务。**意义**：这是"高层学习低层能力边界"的第一个明确表述——层级系统的接口不只是自上而下的命令，也包括自下而上的能力反馈。

### 2026

**[Steerable Policies: Steerable VLA Policies for Embodied Reasoning and Hierarchical Control](https://arxiv.org/abs/2602.13193)** †（2026-02）  
VLM 的常识先验有价值，但如何 grounded 到机器人行为仍是开放问题。先前层级方法中 VLM 与 VLA 的接口通常是自然语言任务指令，这**根本性地限制了 VLM 推理能操控低层行为的程度**。Steerable Policies 是用**多层级抽象的丰富合成指令**训练的 VLA——子任务、运动、grounded 像素坐标。低层可控性提高后，VLM 的预训练知识得以释放，任务泛化改善。两种高层驱动方式都验证了：一个学习得到的高层具身推理器，以及一个通过 in-context learning 被提示对指令抽象做推理的现成 VLM。在大量真实操作实验中，两者都超过先前的具身推理 VLA 与基于 VLM 的层级基线，包括困难泛化与长时域任务。**意义**：直接回应 Hi Robot 暴露的接口问题——把接口从"一句话"扩展为"多抽象层级的指令集"。它与 1A 类别的 π0.7（多模态条件化）是同一思想在学术与工业两侧的表达。

**[MEM: Multi-Scale Embodied Memory for VLA Models](https://arxiv.org/abs/2603.03596)** †（2026-03）  
传统做法是把一串过去观测输入策略。但复杂多阶段任务中，记忆必须在**多个粒度**上表示过去：长期记忆捕捉抽象语义概念（做饭的机器人要记得食谱哪几步已完成），短期记忆捕捉近期事件并补偿遮挡（手臂遮住了想抓的物体时仍记得它在哪）。核心洞见：有效的长时域记忆架构应**结合多种模态**来表示不同抽象层级。MEM 把视频编码器压缩的**视频短期记忆**与**文本长期记忆**结合，使策略能完成长达 **15 分钟**的任务（清理厨房、做烤奶酪三明治）。此外发现记忆使 MEM 策略能**在上下文中智能地调整操作策略**。**意义**：Scholar 引用 66 次。它把"记忆"从"更长的观测窗口"重新定义为"不同模态承载不同时间尺度"，并把上下文内适应作为记忆的副产品。

## 4. 深度分析

### 4.1 接口问题是层级系统的核心

Hi Robot 让 VLM 用自然语言驱动 VLA，随即暴露两个方向的问题：

- **自上而下**：一句话表达不了"怎么做"。Steerable Policies 的答案是扩展指令词汇（子任务、运动、像素坐标）；π0.7（1A）的答案是加入非语言条件（子目标图像、表现元数据）；FRS（1D）的答案是把粗建议通过反向 flow 翻译成动作。
- **自下而上**：高层不知道低层能做什么。LITEN 的答案是让高层从执行结果中学 affordance。

个人推断：未来的层级接口会是**双向、多模态、分抽象层级**的，而"自然语言指令"只是其中最粗的一层。

### 4.2 推理的价值被拆解为表征 + 注意

Efficient Embodied Reasoning 的结论有两层：生成推理提升表征；"注意到"推理才能利用表征。这解释了为什么 ECoT 有效，也指明了省算力的方向——不必在推理时生成完整的推理链，只要训练时学过、推理时能"注意到"关键中间表示即可。这与 LLM 侧"latent reasoning"的方向平行。

### 4.3 记忆的形态由时间尺度决定

MEM 的设计原则——**短期用视频（保留细节，处理遮挡）、长期用文本（抽象、可压缩）**——是一个可推广的原则：越长的时间尺度越需要抽象的表示。这与 1B 类别"评价在粗时间尺度、执行在细时间尺度"的结论呼应，也与多时间尺度控制的传统一致。

### 4.4 上下文内适应：检索、组合、还是真正学习？

Behavioral Exploration、LITEN、MEM 都报告了"上下文内适应"能力。但需要区分：

- **检索**：找到与当前情境相似的过去经验（LITEN 的经验上下文）。
- **组合**：根据历史选择不同的已有行为（Behavioral Exploration 选不同的专家行为）。
- **真正适应**：产生训练数据中没有的新策略。

现有工作主要展示前两种。这正是 SARL（1C）用真实交互优化 prompt 的动机——当上下文不足以产生新行为时，需要真正的学习。

## 5. 与其他类别的连接

- ← **1A**：π0.5 把语义子任务预测编进训练；π0.7 的子目标图像条件是 Steerable Policies 思想的工业版。
- → **1C**：SARL 在 prompt 空间做 RL，可以看作把 LITEN 的上下文内 affordance 学习换成了参数化的 RL。
- → **1D**：FRS 是另一种高层→低层接口。
- ← **1B**：AsyncVLA 的"远程大模型 + 边缘适配器"是层级控制在延迟维度上的表达。
- ↔ **1H**：LITEN 的反思—评估循环与 LLM 侧 Self-Challenging Agents、PAE 的自我评估结构相似。

## 6. 与我的研究方向的连接

- **Reflective Planning 是最接近我设想的工作**：用生成模型想象未来、引导动作选择、反思次优。区别是它在高层 VLM 上以像素 / 语言为单位做反思；skill-level world model 可以在技能粒度上做同样的事，且带有 physics grounding 与不确定性。
- **Steerable Policies 的多层级指令**为 world model 输出定义了接口：world model 规划出的子目标可以直接以"子任务 + 运动 + 像素坐标"的形式下达给 Steerable VLA，无需 VLA 理解 world model 内部表示。
- **LITEN 的"高层学习低层 affordance"** 可以被 world model 替代或增强：与其从真实失败中学 affordance，不如让 world model 在想象中先预测某个技能对当前低层策略是否可达——这正是"action-conditioned skill world model 预测 success/failure outcome"的用处。
- **MEM 的多尺度记忆原则**对 humanoid 长时域任务直接适用：技能级 world model 的状态 \(z_t\) 应该是抽象的（对应文本长期记忆），而低层控制器消费的观测是具体的（对应视频短期记忆）。

## 1. 这个方向在研究什么

一个 generalist 策略号称"什么都能做"，但要证明它、比较它、改进它，需要在很多任务和环境里反复评估——而真实机器人评估慢、贵、难复现，且随着策略越通用，需要的评估环境越多样。这一类论文建设**基础设施**：

1. **自主数据收集**：让机器人车队在无人监督下收集多样、有语义的数据（AutoRT、SOAR）。
2. **规模化评估**：24 小时无人评估站（AutoEval）、分布式众包双盲对比（RoboArena）、real-to-sim 重建的仿真评估（PolaRiS）、用视频生成模型充当评估器（SC3-Eval）。
3. **奖励与价值信号**：通用的视觉语言奖励模型（RoboReward）、从互联网视频学价值函数（ViVa）。

三者合起来构成**数据飞轮**：部署 → 评估 → 产生奖励 / 失败数据 → 再训练 → 再部署。**为什么重要**：互联网 AI 的进步依赖廉价的评估（基准、A/B 测试）和廉价的反馈（点击、点赞）；机器人学习没有这些，所以这类"看起来不像研究"的基础设施工作实际决定了 1A–1D 类别的方法能否被公平比较和规模化。

## 2. 论文逐篇分析（按时间）

### 2024

**[AutoRT: Embodied Foundation Models for Large Scale Orchestration of Robotic Agents](https://arxiv.org/abs/2401.12963)**（2024-01，28 位作者）  
训练具身基础模型的关键瓶颈是缺少物理世界的 grounded 数据。AutoRT 用现有基础模型在**完全未见的场景**中以最少的人工监督扩大机器人部署：VLM 做场景理解与 grounding，LLM 为机器人车队提出多样、新颖的指令，并借助基础模型的知识推理自主性权衡与安全。在多栋建筑中向 20 多台机器人提出指令，通过遥操作和自主策略收集 77k 真实 episode；所收集的"野外"数据显著更多样，且 LLM 让数据收集机器人能对齐人类偏好。**意义**：把基础模型用作**数据收集的调度者**，而非只作为策略。

**[SOAR: Autonomous Improvement of Instruction Following Skills via Foundation Models](https://arxiv.org/abs/2407.20635)**（2024-07）  
自主改进需要解决两个问题：(i) 完全自动化、可扩展的数据收集流程，能采集多样且有语义的机器人数据；(ii) 从**没有人工标注的非最优自主数据**中学习。方法：用 VLM 在新环境中收集并评估有语义的经验，再把指令跟随任务分解为（语义的）语言条件图像生成 + （非语义的）目标到达，使从自主数据中学习变得实际可行。在一组未见环境中，自主数据使策略性能提升 2 倍；开源流水线与 30.5K 轨迹的自主数据集。**意义**：第一次把"部署 → 自主数据 → 改进"的闭环在真实世界完整跑通。

### 2025

**[ViVa: Video-Trained Value Functions for Guiding Online RL from Diverse Data](https://arxiv.org/abs/2503.18210)**（2025-03）  
稀疏奖励的在线 RL 缺少通往目标的中间反馈，而带奖励的专家离线数据很少。奖励塑形需要领域知识。ViVa 提出数据驱动的方法：从广泛可得的**视频数据**（互联网录像、非本任务的示范、任务失败、无目的的环境交互）学习最优目标条件价值模型，用意图条件价值函数把这些价值纳入奖励。实验表明视频训练的价值函数对多种数据源都有效、从人类视频预训练有正迁移、能泛化到未见目标、随数据集规模扩展。**意义**：把"价值函数"本身变成可以从被动视频数据预训练的对象。

**[AutoEval: Autonomous Evaluation of Generalist Robot Manipulation Policies in the Real World](https://arxiv.org/abs/2503.24278)**（2025-03）  
用户像向集群调度器提交作业一样向 AutoEval 队列提交评估任务，系统在**自动成功检测 + 自动场景重置**的框架内调度策略评估。几乎完全消除人的参与，可 24 小时评估，结果与人工评估高度一致。向社区开放了 BridgeData / WidowX 平台上的多个 AutoEval 场景，并期望跨机构建立分布式评估网络。**意义**：评估从"研究生守着机器人"变成"提交作业"。

**[RoboArena: Distributed Real-World Evaluation of Generalist Robot Policies](https://arxiv.org/abs/2506.18123)**（2025-06，32 位作者）  
现有基准依赖重度标准化（固定任务与环境，或集中式挑战赛），无法扩展到 generalist 的广泛任务与环境。RoboArena **众包**评估：评估者可以自由选择任务和环境（多样性易于扩展），但必须对一对策略做**双盲**评估；聚合跨任务、跨环境的成对偏好，得到策略排名。在七所学术机构的 DROID 平台上实例化，通过 600 多个成对真实评估 episode 比较七个 generalist 策略，证明众包方法比集中式评估**更准确地排名**，且更可扩展、有韧性、可信。**意义**：这是机器人版的 Chatbot Arena——用成对偏好而非绝对分数，用多样性而非标准化。

**[PolaRiS: Scalable Real-to-Sim Evaluations for Generalist Robot Policies](https://arxiv.org/abs/2512.16881)**（2025-12，14 位作者）  
仿真评估可扩展，但现有仿真基准与真实世界的视觉、物理差距使其成为不可靠的改进信号，而构建逼真多样的仿真环境需要大量人力。PolaRiS 用神经重建把真实场景的**短视频扫描**变成可交互的仿真环境，并提出简单的仿真数据联合训练配方来弥合剩余差距、实现对未见仿真环境的零样本评估。大量仿真—真实配对评估表明 PolaRiS 与真实 generalist 性能的**相关性远强于**现有仿真基准，且能快速创建多样环境。**意义**：让仿真重新成为可信的评估信号，走向"分布式、民主化"的评估。

### 2026

**[RoboReward: General-Purpose Vision-Language Reward Models for Robotics](https://arxiv.org/abs/2601.00675)**（2026-01）  
真实机器人的奖励要么靠人工标注要么靠脆弱的手工目标；VLM 作为自动奖励模型有潜力但在真实任务上效果不清。贡献：(1) **RoboReward** 数据集与基准，建于 OXE 与 RoboArena 的大规模真实语料；因 OXE 成功样本为主、缺少失败，提出**负例增强流水线**——对成功 episode 做反事实重标注、以及时间裁剪产生部分进度结果，生成校准的负例与 near-miss；(2) 在其上训练 4B / 8B 视觉语言奖励模型。评估发现**没有一个开源或闭源 VLM 在所有任务上都好**；训练的 4B / 8B 模型在短时域任务上超过更大的 VLM；把 8B 模型部署到真实机器人 RL 中，比 Gemini Robotics-ER 1.5 更能改进策略学习，并缩小了与人工奖励 RL 的差距。全部数据、模型与评估套件开源。**意义**：把"奖励模型"变成一个有基准、有开源模型的独立研究对象；它的负例构造思想与 1A 类别 π0.7 用失败数据、1C 类别 Visitation Matching 用失败 episode 形成呼应。

**[SC3-Eval: Evaluating Robot Foundation Models via Self-Consistent Video Generation](https://arxiv.org/abs/2606.18610)**（2026-06）  
动作条件的视频世界模型可以通过模拟策略 rollout 来评估策略，但自回归 rollout 会累积复合误差、多视角必须相互一致、评估器还要泛化到分布外的策略行为。SC3-Eval 把预训练视频基础模型改造成准确的策略评估器，强制三种一致性：(1) **前向—逆向动力学一致性**——同时训练从动作预测帧和从帧恢复动作，把生成 rollout 锚定在物理可行的动作流形上；(2) **跨视角一致性**——从一个相机视角修补另一个，无需显式记忆即可让多相机观测长时间保持一致；(3) **测试时一致性**——推理时复用逆向动力学模式作为每个动作块的不确定性信号，终止漂移的 rollout。还证明 SC3-Eval 的 rollout 能**复现策略在真实中表现出的失败模式**，支持细粒度诊断而非只做排名。在七个真实 VLA 策略上，闭环 Pearson 相关 0.929、MMRV 0.119，超过三个视频模型基线，并泛化到新任务。**意义**：世界模型第一次以"评估器"身份进入 Levine 组的主线，且论文明确把逆向动力学一致性用作不确定性信号。

## 3. 演进脉络

```
2024-01  AutoRT      基础模型调度车队收集数据                      ← 数据收集
2024-07  SOAR        自主数据 → 策略改进 2× 的闭环
2025-03  ViVa        从视频学价值函数                               ← 奖励 / 价值
2025-03  AutoEval    24 小时无人评估站                              ← 评估
2025-06  RoboArena   分布式双盲成对评估，7 所机构
2025-12  PolaRiS     real-to-sim 重建，仿真评估重获可信
2026-01  RoboReward  奖励模型数据集 + 4B/8B 模型 + 负例增强          ← 奖励模型成为独立对象
2026-06  SC3-Eval    视频世界模型作评估器，自一致性 + 不确定性         ← 世界模型进入评估
```

评估这条线在 2025 年密集成型（AutoEval → RoboArena → PolaRiS），随后 2026 年向两个方向延伸：奖励模型（RoboReward）与世界模型评估器（SC3-Eval）。

## 4. 深度分析

### 4.1 评估的三个维度：真实 / 仿真 / 想象

| 维度 | 工作 | 代价 | 可信度 | 可扩展性 |
|---|---|---|---|---|
| 真实（自动化） | AutoEval | 硬件 + 场景搭建 | 最高 | 受硬件数量限制 |
| 真实（众包） | RoboArena | 协调多机构 | 高（双盲） | 随参与者线性扩展 |
| 仿真（重建） | PolaRiS | 视频扫描 + 重建 | 与真实相关性强 | 高 |
| 想象（视频模型） | SC3-Eval | 一次训练评估器 | Pearson 0.929 | 最高 |

从上到下代价递减、可扩展性递增，但可信度需要不断用真实评估去校准。个人推断：未来会形成分层评估——大量候选先在 SC3-Eval / PolaRiS 上筛，少数进入 RoboArena / AutoEval。

### 4.2 失败数据的价值被重新发现

机器人数据集（如 OXE）以成功示范为主。RoboReward 指出这使奖励模型缺少负例，并**主动构造**负例（反事实重标注、时间裁剪）；SOAR 则从自主收集的非最优数据中学习。这与 1A 类别 π0.7 把失败数据纳入训练、1C 类别 Success Visitation Matching 用失败 episode 塑形奖励形成一个共同趋势：**失败不是要清洗掉的噪声，而是最稀缺的监督信号**。

### 4.3 奖励模型与价值函数的分工

- RoboReward：判断一段执行是否成功 / 进度如何——**事后评价**，对策略无关。
- ViVa：估计从当前状态到目标还有多远——**事前预估**，可引导探索。
- 1D 类别的价值函数（V-GPS、QGF）：评价具体动作——**逐步引导**。

三者是同一个"评价路径"在不同时间尺度上的实例。RoboReward 发现"没有一个 VLM 在所有任务上都好"，说明通用奖励模型还远未成熟。

### 4.4 世界模型以评估器身份进场

SC3-Eval 是 Levine 组把视频世界模型带进主线的方式：不是用它规划或生成训练数据，而是用它**评估策略**。理由清晰——评估对世界模型的要求（区分好坏策略、复现失败模式）比规划（每步精确）宽松，且评估错误的代价低于执行错误。三种一致性约束（前向—逆向、跨视角、测试时终止）也是对"世界模型如何可信"这一问题的具体回答。

## 5. 与其他类别的连接

- ← **1A**：DROID 平台承载 RoboArena 与 RoboReward；SC3-Eval 评估的对象是 VLA。
- → **1C**：RoboReward 直接用于真实机器人 RL；ViVa 引导在线 RL。
- ↔ **1D**：RoboReward / ViVa 与 V-GPS / QGF 的价值函数构成完整的评价路径。
- ← **1B**：SC3-Eval 的不确定性信号按"动作块"计算，与动作分块的粒度一致。
- ↔ **1H**：PAE、Self-Challenging Agents 用 VLM 评估器作奖励，是 LLM 侧的 RoboReward。

## 6. 与我的研究方向的连接

- **SC3-Eval 是 skill-level world model 最直接的参照**：它证明了 (a) 世界模型作为 verifier / evaluator 是可行且有价值的定位，(b) 逆向动力学一致性可以作为不确定性信号来终止不可信的 rollout。我的 world model 可以在技能粒度上做同样的事，并加上 physics-based 可行性约束——SC3-Eval 靠数据学到的"物理可行动作流形"，在 humanoid 上可以部分由显式动力学提供。
- **不确定性驱动的 rollout 终止**（SC3-Eval 的第三种一致性）正是我关于"明显 OOD 时拒绝 imagined rollout"的设想的一个已实现版本。
- **PolaRiS 的 real-to-sim** 对 crowd navigation 与 humanoid 评估同样适用：把真实人群场景扫描重建，在仿真中评估 uncertainty-aware 策略。
- **RoboReward 的负例构造**（反事实重标注、时间裁剪）可以直接用于训练 world model 的 success / failure outcome 头，解决"失败样本太少"的问题。

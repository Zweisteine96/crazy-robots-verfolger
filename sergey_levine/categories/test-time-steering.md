## 1. 这个方向在研究什么

现代机器人策略大多是 **diffusion 或 flow-matching 生成模型**：不是直接输出一个动作，而是从随机噪声出发、经多步"去噪"生成一个动作（或动作块）。这类策略能表达多模态的动作分布（同一个状态下有多种合理做法），在模仿学习中扩展性很好。

问题是：**如何用一个价值函数（Q 函数，估计"这个动作有多好"）来改进这样的策略？** 传统 actor–critic 要把 Q 的梯度反传回策略，但对多步去噪过程反传（backpropagation through time）数值不稳定，这是本类别所有论文都在绕开的核心障碍。两条路线：

- **训练时**：设计新的目标，让 flow / diffusion 策略在训练中吸收价值信息，同时避免不稳定的反传（FQL、CFGRL、QAM、RQL）。
- **测试时**：策略只做标准 BC 训练，价值函数单独训练；推理时用价值对候选动作重排序、做梯度引导、或在噪声空间搜索，**完全不重训策略**（V-GPS、QGF、FRS）。

**为什么重要**：这与大语言模型的"生成器 + 验证器"测试时计算范式（best-of-N、reward-model 引导、搜索）是同构的。如果测试时引导足够好，就可以把稳定但"只会模仿"的大型 BC 策略与一个较小的价值模型解耦——大模型负责提出动作，小模型负责挑选或修正。2026 年这一类别出现 4 篇（QGF、FRS、RQL、QAM），是 Levine 组当年最集中的新方向。

## 2. 论文逐篇分析（按时间）

### 2024

**[V-GPS: Steering Your Generalists — Improving Robotic Foundation Models via Value Guidance](https://arxiv.org/abs/2410.13816)**（2024-10）  
generalist 的训练数据质量参差不齐：人类示范不完美，数据越大越难只保留高质量样本，跨 embodiment 数据的最优性也不清楚。V-GPS 在**部署时**用离线 RL 学到的价值函数对 generalist 的候选动作**重排序**——不需要微调甚至不需要访问策略权重。同一个价值函数改进了 5 个不同架构、不同训练数据的 SOTA 策略，在多个机器人平台共 12 个任务上一致提升。**意义**：本类别的起点，确立了"价值函数可以是策略无关的外挂"这一命题。

### 2025

**[Flow Q-Learning (FQL)](https://arxiv.org/abs/2502.02538)**（2025-02）  
用表达力强的 flow 策略建模数据中任意复杂的动作分布，但用 RL 训练 flow 策略很棘手（生成过程是迭代的）。FQL 的做法：**用 RL 训练一个表达力强的 one-step 策略**，而不是直接引导迭代 flow 策略去最大化价值——完全避开不稳定的递归反传，消除测试时昂贵的迭代生成，同时基本保持表达力。在 73 个 OGBench 与 D4RL 任务（状态与像素）上离线及 offline-to-online 表现强。**意义**：这是"蒸馏"路线——把 flow 的表达力转移到一个可被 RL 优化的简单策略里。

**[CFGRL: Diffusion Guidance Is a Controllable Policy Improvement Operator](https://arxiv.org/abs/2505.23458)**（2025-05）  
RL 的核心是"超越数据中的表现"，但扩展 RL 系统很难；生成建模则扩展性好、训练简单。CFGRL 推导出 **diffusion guidance 与策略改进之间的直接关系**：用监督学习的简单性训练，却能超越数据中的策略。离线 RL 上观察到可靠趋势——**guidance 权重越大，性能越高**。尤其重要的是，CFGRL **可以不显式学价值函数**，从而把目标条件 BC 这类简单监督方法推广为"更偏向最优"，白拿性能提升。**意义**：把 classifier-free guidance 这个生成模型的旋钮重新解释为一个可调的策略改进算子，并揭示它与 RL 的等价性。

### 2026

**[QAM: Q-learning with Adjoint Matching](https://arxiv.org/abs/2601.14234)**（2026-01）  
直面长期难题：如何用参数化 Q 函数高效优化 diffusion / flow 策略。有效优化需要 critic 的一阶（梯度）信息，但对多步去噪反传不稳定；已有方法要么只用价值、丢掉梯度，要么用近似——牺牲表达力或引入偏差。QAM 借用生成建模中的 **adjoint matching**，把 critic 的动作梯度转化为逐步的目标函数，**没有不稳定的反传，最优解处策略无偏且表达力完整**。结合 TD 回传学 critic，在困难稀疏奖励任务的离线与 offline-to-online RL 上一致超过先前方法。**意义**：这是"训练时"路线上最干净的解——既用梯度又不反传。

**[QGF: Test-Time Gradient Guidance of Flow Policies in RL](https://arxiv.org/abs/2606.11087)**（2026-06）  
diffusion / flow 策略在监督模仿学习中扩展稳定，但接入 RL 需要特殊目标或反传去噪过程，影响稳定性与可扩展性。QGF 问：**仅靠测试时的策略改进、保持监督训练不变**，能否成为有竞争力的替代？做法：预训练一个参考 flow 策略（标准 BC）和一个价值 critic；测试时用**价值梯度引导**参考策略生成更高价值的动作，不做任何额外的策略学习。在高维动作空间的单任务与目标条件离线 RL 基准上超过先前测试时 RL 方法，与 SOTA 训练时算法有竞争力且**运行成本低得多**；因避开 actor–critic 训练的不稳定，**随模型规模扩展表现更好**。**意义**：这是本类别的核心论点——策略优化可以完全发生在推理时，且这种分离反而带来可扩展性。

**[FRS: Improving Robotic Generalist Policies via Flow Reversal Steering](https://arxiv.org/abs/2606.13675)**（2026-06）  
generalist 学到了丰富的行为先验，但当直接命令它失败时，需要一种方法从先验中"调出"合适的动作。FRS 针对 flow generalist：取一个次优但"合理"的动作，**反向通过 flow 策略找到它对应的潜噪声**，再映射到附近的 generalist 动作模式。三种用法：(1) 把人类或 VLM 的粗粒度语义引导转成好的机器人动作，改善零样本控制；(2) 用 BC 把这种收益蒸馏进一个输出噪声的辅助策略——**不到一分钟训练带来最多 95% 的绝对成功率提升**；(3) 用语义知识引导 RL 探索，改进标准 RL 无法改进的任务。**意义**：它把 DSRL 的"噪声空间"思想变成一个可逆的接口——任何外部建议（人、VLM、粗规划器）都可以通过反向 flow 被"翻译"成 generalist 会做的动作。

**[RQL: Reversal Q-Learning](https://arxiv.org/abs/2606.17551)**（2026-06）  
从"扩展 MDP"框架出发：把 flow 的每个精炼步视为 MDP 中的一个独立动作。为在此框架下做离策略 RL，(1) 通过**反转 flow 生成虚拟 on-policy 轨迹**以兼容先验数据；(2) 用偏差—方差降低技术缓解离策略 RL 的 horizon 之咒。优点：无需 backpropagation through time、更好地利用价值函数、直接训练完整的表达力强的 flow 策略。在 50 个困难仿真机器人任务上，取得 flow-based 离线 RL 中最佳平均性能。**意义**：与 QAM 一样属于训练时路线，但用的是"把去噪步当作决策步"的 RL 视角，而非生成模型的 adjoint 技巧。

## 4. 深度分析

### 4.1 同一个障碍，五种绕法

所有论文面对同一个技术障碍：**对多步去噪过程做梯度反传不稳定**。绕法各异：

| 方法 | 策略是否重训 | 是否用价值梯度 | 表达力 | 推理开销 |
|---|---|---|---|---|
| V-GPS | 否 | 否（只用价值排序） | 受基座限制 | 多次采样 + 打分 |
| FQL | 是（蒸馏 one-step） | 是 | 略降 | 最低（单步） |
| CFGRL | 是（guidance 作训练目标） | 可不学价值 | 完整 | 标准 |
| QAM | 是 | 是（adjoint 转为逐步目标） | 完整、无偏 | 标准 |
| QGF | 否 | 是（测试时梯度引导） | 完整 | 引导步额外计算 |
| FRS | 否（可选蒸馏） | 否（用外部建议） | 完整 | 一次反向 + 一次前向 |
| RQL | 是 | 是（扩展 MDP 中的 TD） | 完整 | 标准 |

### 4.2 测试时 vs 训练时：不是替代而是光谱

QGF 的论点是测试时引导"竞争力相当且更便宜、更可扩展"。但同一季度 RQL、QAM 也在推进训练时路线。个人推断：两者会长期共存——训练时方法用于有充足离线数据、可以承受训练成本的场景；测试时方法用于基座策略是黑盒（如商业 VLA）、或需要快速适配的场景。FRS 的"可选蒸馏"甚至提供了从测试时到训练时的平滑过渡。

### 4.3 与 LLM 测试时计算的同构

| LLM 侧（1H 类别） | 机器人侧（本类别） |
|---|---|
| Best-of-N + reward model | V-GPS（采样 + 价值排序） |
| 验证器引导的搜索 / RL 优于蒸馏（Scaling TTC Without Verification） | QGF 的"测试时价值引导可与训练时 RL 竞争" |
| Digi-Q 的 Best-of-N 策略提取 | V-GPS 同样用重排序提取策略 |

差别在于：机器人侧的"验证器"必须处理连续动作、部分可观测和实时约束，因此需要梯度引导（QGF）而不能只靠离散重排序。

### 4.4 噪声空间正在成为 generalist 的通用接口

DSRL（1C）在噪声空间做 RL；FRS 通过反向 flow 把外部动作映射进噪声空间；QGF 在生成过程中用梯度移动样本。三者共同指向：**flow generalist 的潜噪声空间是一个低维、安全（任何点都映射为合理动作）、可逆的接口**，人、VLM、RL、价值函数都可以通过它与 generalist 交互而不触碰权重。

## 5. 与其他类别的连接

- ← **1A**：被引导的对象都是 π0 一类的 flow generalist。
- ↔ **1C**：DSRL（噪声空间 RL）与 FRS（噪声空间反演）是同一接口的两种用法；QAM / RQL 也可作为 RL 后训练算法。
- ← **1G**：所有价值函数的可扩展性依赖 Stop Regressing、Horizon Reduction 等结论；FQL 在 OGBench 上评估。
- ↔ **1H**：与 LLM 侧的验证器驱动测试时计算同构。
- → **1E**：FRS 能把 VLM 的粗语义引导翻译为动作，是层级系统中高层→低层接口的另一种实现。

## 6. 与我的研究方向的连接

- **skill-level world model 作为 verifier**：QGF / V-GPS 需要一个价值函数来评价候选动作；world model 在技能层面的预测（状态、进度、成败）加上 physics-based feasibility 检查，可以充当这个评价器——尤其是在真实 reward 稀疏、价值函数难学的长时域 humanoid 任务上。
- **不确定性驱动的计算分配**：QGF 的引导步数、V-GPS 的采样数都是测试时算力；用 world model 的不确定性决定"在哪些状态多采样、多引导"，正是我关于"中等不确定性 → 增加 world-model samples"的设想的直接实例。
- **FRS 的反向 flow 接口**：world model 规划出的粗糙动作 / 子目标可以通过 FRS 被翻译成 generalist 的动作模式，这提供了一条不需要 generalist 直接理解 world model 输出的集成路径。
- **物理 verifier 与价值 verifier 的分工**：价值函数回答"好不好"，physics grounding 回答"能不能"；两者可以在同一个测试时引导框架中串联。
